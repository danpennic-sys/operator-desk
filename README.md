# Operator Desk

Local-first quoting desk for Operator Pages. Built on the FieldQuote template schema already in `danpennic-sys/fieldquote`.

This is the missing software behind the Operator ($349) and Command ($1,497) asset packs. Templates stay data. This app is what the buyer runs on a phone or laptop with no account and no network.

## Run

Open `index.html` in any browser. Works offline after the first load. Quotes live in `localStorage`.

Storefront: open `sell.html`.

## Name note

`fieldquote.app` is an unrelated UK product. Do not ship this under that name. Operator Desk / Operator Pages is the storefront name.
